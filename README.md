# 🥅 Goalie Stats Pro

Современная версия приложения для анализа бросков вратаря по зонам.
Переписано с монолитного HTML на **React + TypeScript + Vite + Tailwind CSS**.

## ✨ Возможности

- **🏒 Интерактивная схема поля** — кликайте по зонам для записи сейвов и голов
- **💾 Автосохранение** — все данные сохраняются в браузере мгновенно (Zustand Persist)
- **📑 Вкладки (Роутинг)** — Game Stats / Period / Dashboard через React Router
- **⚡ Современный стек** — Vite, TypeScript, Tailwind CSS, Zustand
- **🔄 Режимы** — переключение Save/Goal, выбор периода, времени, атрибутов гола
- **⇄ Зеркалирование** — переворот схемы (сетка справа/слева)
- **📊 Статистика** — SV%, GAA, разбивка по зонам в реальном времени

## 🚀 Запуск

```bash
cd goalie-stats-app
pnpm install
pnpm run dev
```

Откройте http://localhost:5173

## 📦 Сборка для продакшена

```bash
pnpm run build
pnpm run preview
```

## 💾 Хранение данных

Данные хранятся в `localStorage` под ключом `goalieZoneStatsV2`.
Экспорт/импорт JSON можно добавить в следующем этапе разработки.

## 🔧 Миграция со старой версии

Старые данные из `goalie-stats.html` (ключ `goalieZoneStatsV1`) могут быть
импортированы через функцию импорта JSON (будет реализована в Dashboard).
