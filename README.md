# 🥅 Goalie Stats Pro

Приложение для анализа бросков вратаря по зонам.
**React + TypeScript + Vite + Tailwind CSS**, тёмная «трансляционная» тема.

## ✨ Возможности

- **🏒 Интерактивная схема поля** — кликайте по зонам для записи сейвов и голов
- **💾 Автосохранение** — все данные сохраняются в браузере мгновенно (Zustand Persist)
- **☁️ Синхронизация** — Яндекс.Диск через REST API (OAuth-токен, шифрование AES-256-GCM паролем сайта), автобэкап через 10 с после изменений
- **📑 Вкладки (Роутинг)** — Game / Season / Dashboard / Seasons через React Router
- **🔄 Режимы** — переключение Shot/Goal, выбор периода, времени, атрибутов гола
- **⇄ Зеркалирование** — переворот схемы (сетка справа/слева)
- **📊 Статистика** — SV%, Danger SV%, GAA, разбивка по зонам в реальном времени
- **🏆 Сезоны и команды** — игры привязаны к сезонам, у сезонов есть команды с логотипами

## 🚀 Запуск

```bash
cd goalie-stats-app
pnpm install
pnpm run dev
```

Откройте http://localhost:5173 (или просто запустите `start.sh` / `Запустить.command`).

## 📦 Сборка для продакшена

```bash
pnpm run build
pnpm run preview
```

## 💾 Хранение данных

Данные хранятся в `localStorage` под ключом `goalieZoneStatsV2`.
Бэкап/перенос: экспорт в JSON-файл (или drag & drop файла на страницу)
и синхронизация с Яндекс.Диском (файл `Goalie Stats Backups/sync-data.json`,
зашифрован паролем сайта).

## 🔧 Миграция со старой версии

Данные v1 (ключ `goalieZoneStatsV1`) мигрируют автоматически при первом
запуске; также поддерживается импорт старых JSON-бэкапов (команды и сезоны
будут созданы по умолчанию).
